# KLSubjectVision 移行

> <span lang="ja">[English](../../README.md) · [简体中文](../zh-Hans/README.md) · [繁體中文](../zh-Hant/README.md) · [日本語](../ja/README.md) · [한국어](../ko/README.md)</span>

最初に、各サムネイルで使用している寸法、切り抜き方法、透明度、画像形式、保存先、キャッシュキーを記録します。次に、アプリ内の用途をリクエストへ変換する処理を1か所にまとめ、cutout、fallback、room の結果をテストデータで比較します。既存のキャンセル、重複排除、保存、キャッシュはそのまま維持し、出力が同等であることを確認してから重複した画像配置処理を削除します。

## チェックリスト

- [ ] アプリとの境界で画像の向きを補正し、`CGImage` に変換します。
- [ ] 人物、動物、商品には `.subject` を、場所、文書、スクリーンショットには `.room` を指定します。
- [ ] 大きな画像や複数画像の処理は、メインアクターの外で実行します。
- [ ] `output.kind` を診断に利用し、エンコード、保存、キャッシュはアプリ側で管理します。
