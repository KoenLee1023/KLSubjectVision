# KLSubjectVision アーキテクチャ

## 概要

入力は `CGImage` と明示的なリクエスト、出力は正方形画像と処理経路に限定しています。`.subject` では Vision で前景マスクを作成し、すべての被写体を含む範囲で切り抜いた後、Core Image を経由して透明な RGBA 画像へ配置します。差し替えた抽出器を使う場合は Vision を呼びません。抽出に失敗した場合は `.room` と同じ配置処理を使います。

## 動作保証

- Apple Vision による前景の切り抜き
- 余白を指定できる、被写体全体を収める配置
- 場所写真とフォールバック時は正方形いっぱいに配置
- テスト用の切り抜き処理を差し替え可能
- cutout、fallback、room のどの経路を使ったか結果から確認可能

## 責務の境界

このパッケージが扱うのは `CGImage` の変換だけです。UIImage または NSImage の読み込み、画像の向きの補正、タスクの実行管理とキャンセル、エンコード、保存先、キャッシュキー、添付ファイルの管理はアプリ側で行ってください。

この API は計算結果だけを返し、アプリ側の状態は変更しません。入力、設定、システムフレームワークの挙動が同じであれば、同じ結果を返します。
