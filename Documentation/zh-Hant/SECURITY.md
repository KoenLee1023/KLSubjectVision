# 安全政策

發現疑似安全漏洞時，請勿建立公開 Issue。請私下聯絡儲存庫擁有者，並提供受影響版本、重現條件、潛在影響與建議的緩解措施。請勿附上真實使用者資料、憑證或未公開 App 的測試資料。0.1.x 屬於穩定版之前的版本。穩定版發布後會明確列出仍受支援的版本分支。
