# KLSubjectVision 마이그레이션

> <span lang="ko">[English](../../README.md) · [简体中文](../zh-Hans/README.md) · [繁體中文](../zh-Hant/README.md) · [日本語](../ja/README.md) · [한국어](../ko/README.md)</span>

먼저 각 썸네일의 픽셀 크기, 자르기 방식, 투명도, 이미지 형식, 저장 위치, 캐시 키를 기록합니다. 앱의 이미지 용도를 요청으로 바꾸는 변환을 한곳에 모으고 cutout, fallback, room 결과를 테스트 데이터로 비교합니다. 기존 취소, 중복 제거, 저장, 캐시 처리는 유지하고 출력이 같은지 확인한 뒤 중복된 이미지 배치 코드를 삭제합니다.

## 체크리스트

- [ ] 앱 경계에서 이미지 방향을 보정한 뒤 `CGImage`로 변환합니다.
- [ ] 사람, 동물, 제품에는 `.subject`를, 장소, 문서, 스크린샷에는 `.room`을 지정합니다.
- [ ] 큰 이미지나 여러 이미지는 메인 액터 밖에서 처리합니다.
- [ ] `output.kind`를 진단에 사용하고 인코딩, 저장, 캐시는 앱에서 관리합니다.
